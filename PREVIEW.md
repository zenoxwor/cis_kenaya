Preview instructions for CIS Kenya site

1) Quick in VS Code (Live Server extension)
- Open this folder in VS Code (File → Open Folder → select this repo).
- Install "Live Server" (Ritwick Dey) or use Live Preview.
- Open index.html and click "Go Live".

2) Run the included scripts (Windows)
- Double-click run-server.bat or run run-server.ps1 from PowerShell.
- Visit http://localhost:8000

3) Optional: VS Code tasks
- Open .vscode/tasks.json and run the "Run local server (Windows)" task.
